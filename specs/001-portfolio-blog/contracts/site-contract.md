# 契约：站点接口

**Feature**: `001-portfolio-blog` | **Date**: 2026-09-12

本契约定义站点对外暴露的地址、静态资源布局与发布触发方式。这些是站点的**外部接口**：地址一旦发布即成为承诺（FR-015），发布方式一旦确定即成为可迁移的前提（FR-029、FR-034）。

---

## 1. 路由契约

| 路径 | 内容 | 对应需求 |
|---|---|---|
| `/` | 首页：身份、定位、精选项目、最新文章、联系方式 | FR-001、FR-002 |
| `/about/` | 关于我：简介、技能、经历、联系方式与公开账号 | FR-003、FR-036 |
| `/projects/` | 项目列表 | FR-007 |
| `/projects/<slug>/` | 项目详情 | FR-008、FR-009、FR-010 |
| `/posts/` | 文章列表（按发布日期倒序） | FR-012 |
| `/posts/<slug>/` | 文章详情 | FR-013、FR-014 |
| `/rss.xml` | 订阅源 | FR-022 |
| `/sitemap-index.xml` | 站点地图 | FR-023 |
| `/tags/`、`/tags/<tag>/` | 标签索引与聚合（模板自带） | FR-016 |
| `/archives/` | 归档（模板自带） | FR-016 |
| `/search/` | 站内检索 | FR-025 |
| `/404.html` | 未找到 | — |

**注意**：文章路径前缀由模板的 `/posts/` 决定，不使用早期草案中的 `/writing/`。理由是沿用
模板既有路由可避免改动页面目录与站点地图过滤逻辑，符合宪法 I。`/projects/` 为新增前缀。

**稳定性规则**：

- `<slug>` 来自内容文件名，发布后 MUST NOT 变更。
- 已发布地址 MUST NOT 因标题修改、正文修订、排版调整而失效。
- 站点 MUST 支持尾斜杠形式；若启用不带尾斜杠的访问，MUST 以重定向指向尾斜杠形式，避免同一内容出现两个地址。
- 站点迁移到另一台服务器或另一处托管时，上表路径 MUST 保持不变（FR-029、SC-009）。

---

## 2. 静态资源契约

| 路径 | 内容 | 说明 |
|---|---|---|
| `/demos/<slug>/` | 可交互演示产物 | 由项目 frontmatter 的 `demo` 字段引用；完全自包含，不参与站点构建 |
| `/_astro/…` | 构建期生成的资源 | 由构建工具管理，不作为对外承诺，允许随构建变化 |
| `/favicon/…` | 站点图标 | — |

**规则**：

- `public/demos/<slug>/` 下的产物 MUST 自包含，MUST NOT 依赖站点自身构建流程。
- 演示加载失败或超时 MUST NOT 影响页面其余内容的阅读（边界情况、User Story 6 场景 3）。
- 构建期 MUST 校验每个 `demo` 字段指向的目录真实存在。

---

## 3. 分享与订阅契约

- 每个页面 MUST 输出 `title`、`description` 与规范地址（canonical）元信息。
- 每个页面 MUST 输出分享预览信息（Open Graph / Twitter Card）：标题、摘要、封面；无封面时使用站点默认图（FR-024）。
- `/rss.xml` MUST 包含全部已发布文章，按日期倒序，含标题、摘要、日期与正文；草稿 MUST 不出现（FR-020、FR-022）。

---

## 4. 发布契约

**触发方式**：站主向服务器上的裸仓库推送后，由服务端钩子自动完成构建与发布。站主 MUST NOT 需要执行任何手工部署命令（FR-019）。

**发布流水线**（顺序固定）：

1. 钩子在工作区拉取最新提交
2. 安装依赖（若锁定文件未变化则跳过）
3. 构建站点（Astro 构建 + Pagefind 索引）
4. 运行体积预算检查与链接检查
5. 全部通过后，将新产物发布到新的发布目录，再原子切换服务目录指向
6. 保留最近若干个发布目录，供回滚

**失败处理**：

- 任一步骤失败 MUST 中止发布，MUST NOT 切换服务目录，MUST NOT 让访客看到半成品。
- 失败信息 MUST 出现在钩子输出中，站主能据此定位。
- 服务目录 MUST NOT 在构建过程中被修改（构建与发布目录分离）。

**构建前置条件（实测得出，见 `../verify.md`）**：

- 构建 MUST NOT 依赖任何运行期外部网络请求。模板原有的 Google Fonts 构建期抓取已移除，站点正文
  改用系统字体栈；分享图字体为**仓库内的子集文件**，构建期从本地读取。任何重新引入构建期外部
  依赖的改动 MUST 被否决。
- 分享图字体 MUST 覆盖全部内容的字符。构建期 MUST 执行字符覆盖检查，**缺字 MUST 导致构建失败**
  ——因为渲染器对缺失字形是**静默留空白**，既不报错也不显示占位符，不检查就等于无声降级。
- Node.js MUST ≥ 22.12.0（模板 `engines` 要求）。
- 构建产物 MUST NOT 被写回源码目录。模板原 `build` 脚本会把 Pagefind 索引复制到 `public/`，本
  项目 MUST 保留该行为并在 `.gitignore` 中排除 `public/pagefind/`，或改写脚本以避免污染。

**服务方式**：静态文件由 Caddy 直接提供，证书自动申请与续期；站点 MUST NOT 依赖任何需要服务端运行时的能力（宪法 III）。

**迁移前提**：内容、页面代码与 `deploy/` 下的部署描述同属本仓库。更换服务器时 MUST 只需重放 `deploy/` 内容，MUST NOT 需要修改任何内容文件或页面地址（FR-029、FR-034、SC-009）。

---

## 5. 安全与隐私契约

- 构建产物 MUST NOT 包含 `.env`、令牌、密钥或抓取类项目的账号配置（FR-032）。
- 站点 MUST NOT 公开手机号与简历文件（FR-004、FR-036）。
- 构建产物 MUST NOT 依赖按访问量计费的服务（FR-033）。
- 站点 MUST NOT 包含用户注册、登录或任何服务端数据存储（FR-031）。

---

## 6. 性能契约

| 指标 | 目标 | 对应需求 |
|---|---|---|
| 国内首屏可见 | ≤ 3 秒（常规宽带与 4G） | SC-003 |
| 单页首屏 JS | ≤ 50 KB（gzip 后） | 性能目标 |
| 静态资源总量（不含图片与 demo） | ≤ 1 MB | 性能目标 |
| 站内检索响应 | ≤ 1 秒 | SC-011 |
| 单篇内容媒体总量 | ≤ 5 MB | 宪法「内容与隐私约束」 |

预算检查在发布流水线第 4 步执行；超出预算 MUST 中止发布，除非站主显式调整本契约中的数值。

任务 T012 建立并接入构建。此处数值即为可执行契约。）*
