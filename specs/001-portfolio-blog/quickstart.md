# Quickstart：端到端验证指南

**Feature**: `001-portfolio-blog` | **Date**: 2026-09-12

本文件是站点的验证与运行指南，覆盖 `spec.md` 的全部成功标准。实现细节见 `plan.md` 与 `contracts/`；本文件只负责回答"怎么证明它做到了"。

---

## 前置条件

- Node.js **≥ 22.12.0**（模板 `engines` 要求）
- 一台已开通的香港/新加坡轻量服务器，Caddy 已安装
- 一个已解析到该服务器的域名
- `deploy/` 下的 Caddyfile 与钩子脚本已按 `contracts/site-contract.md` 的发布契约就位
- **构建不需要外网**：模板原有的 Google Fonts 构建期抓取已移除（见 `verify.md` 第四节）。若构建
  过程出现任何对外部域名的请求，视为回归缺陷

## 本地运行

```bash
npm install
npm run dev        # 本地预览，默认 http://localhost:4321
npm run build      # 类型检查 + 生成静态产物到 dist/ + 建立检索索引
npm run preview    # 以静态方式预览产物，最接近线上行为
```

**注意**：

- 站内检索与分享元信息只在 `build` 后存在，验证这两项必须用 `npm run preview`，不能用 `dev`。
- 若在受限环境中构建报错 `ENOENT: ... mkdir '/home/<user>/.config/astro'`，设置
  `ASTRO_TELEMETRY_DISABLED=1` 即可，与站点本身无关。

## V1 — 构建可用性与内容迁移（SC-006）

1. 把一份现有 Markdown 素材原样（仅补 frontmatter）放入 `src/content/posts/`，执行 `npm run build`。
2. **预期**：构建成功；正文无需改写即完整呈现；代码块、表格、图片均正常显示。

3. 用 3 篇不同来源的素材重复上一步。
4. **预期**：3 篇全部通过，正文内容无丢失。
5. 故意写错一个必填字段（例如漏掉 `summary`），执行构建。
6. **预期**：构建**失败**并指出具体文件与字段，绝不产出坏页面。

## V2 — 新增内容不改代码（SC-005）

1. 记录 `src/layouts/`、`src/components/`、`src/pages/` 的改动状态。
2. 新增一个项目：只添加 `src/content/projects/<slug>.md` 与相关图片。
3. **预期**：项目出现在列表与详情路由中，页面代码改动为**零**。

## V3 — 访客快速认识站主（SC-001、SC-002）

1. 打开首页，不做任何滚动与点击。
2. **预期**：首屏可见站主身份、主要技术方向与至少一种联系方式。
3. 从首页点击进入任一项目详情页，数所需点击次数。
4. **预期**：≤ 2 次。
5. 在任一内页查找返回首页与联系站主的入口。
6. **预期**：两者均可见。
7. 打开"关于我"，检查内容与公开账号。
8. **预期**：有简介、技能、经历、邮箱与公开技术账号；**没有**手机号、**没有**简历下载入口。

## V4 — 项目详情完整性（FR-008 / FR-009 / FR-010）

对一个**同时有 repo 和 demo** 的项目，逐项确认：问题、方案、取舍、架构图、截图、结果与现状、仓库入口、演示入口。

再取一个**没有 repo、没有 demo** 的项目，确认：

- 源码入口呈现为不可用状态，而不是指向 404 的链接
- 演示区域**完全不出现**，也没有留下空白占位

## V5 — 订阅与分享（SC-007、SC-010）

1. `npm run build && npm run preview`，把订阅源地址导入一个阅读器。
2. **预期**：可见全部已发布文章的标题与摘要；草稿不出现。
3. 发布一篇新文章并完成上线，等待不超过 1 小时。
4. **预期**：阅读器中出现该文章。
5. 把一篇文章地址粘贴到社交平台或分享调试工具。
6. **预期**：预览卡片显示正确的标题、摘要与封面；无封面时使用站点默认图，不出现破图。
7. 用搜索引擎检索文章标题（首次收录可能需要数天）。
8. **预期**：能检索到该文章地址。

## V6 — 移动端阅读（SC-008）

在移动端与桌面端分别打开：首页、项目列表、项目详情、文章列表、含宽表格与长代码行的文章。

- **预期**：均无整页横向滚动；宽表格与代码块在自身容器内滚动。
- **预期**：明暗两种显示模式均可切换且内容可读。

## V7 — 站内检索（SC-011）

1. 在 `npm run preview` 环境下，用正文中出现过、但标题里没有的中文关键词检索。
2. **预期**：1 秒内返回匹配的文章与项目。
3. 输入一个不存在的关键词。
4. **预期**：给出明确的空结果提示，而不是空白页。

## V8 — 发布自动化（SC-004、FR-019）

1. 修改任意内容并推送到服务器的裸仓库。
2. 计时，全程**不执行任何手工部署命令**。
3. **预期**：5 分钟内线上可见更新，且更新过程中访问站点不会看到半成品。
4. 故意提交一处会让构建失败的改动并推送。
5. **预期**：发布中止，服务目录未被切换，线上仍是上一个正常版本；钩子输出中能看到失败原因。
6. 修复后重推。
7. **预期**：恢复正常发布；如需回滚，可切回上一个发布目录。

## V9 — 隐私与合规（FR-032、FR-004、FR-033）

1. 在构建产物中搜索常见凭证特征（token、secret、password、账号配置文件名）。
2. **预期**：无命中。
3. 逐项检查含第三方平台数据的项目截图与正文。
4. **预期**：无账号信息、无 token、无第三方隐私内容。
5. 检查站点没有任何登录、注册入口，也没有依赖按访问量计费的服务。
6. **预期**：均无。

## V10 — 性能预算（SC-003）

1. 在 `npm run preview` 下用浏览器开发者工具的移动端网络限速（4G）加载首页。
2. **预期**：首屏内容 3 秒内可见。
3. 查看单页首屏 JS 体积与静态资源总量。
4. **预期**：JS ≤ 50 KB（gzip），静态资源 ≤ 1 MB（不含图片与 demo）。
5. 检查单篇内容的媒体总量。
6. **预期**：≤ 5 MB。

## V11 — 可迁移性（SC-009、FR-029、FR-034）

1. 在另一台服务器上重放 `deploy/` 内容，指向同一份仓库。
2. **预期**：1 小时内完成；内容与页面地址完全不变；无需修改任何内容文件或页面代码。

## M0 上线验收清单

首期只需下列项全部通过即可对外发布，其余项可随后补齐：

- [ ] `npm run build` 通过，构建期内容校验生效（V1）
- [ ] 首页、"关于我"、项目列表、2 个项目详情、文章列表、1 篇文章、订阅源全部可访问
- [ ] 首页首屏可见身份与联系方式（V3 步骤 1–2）
- [ ] 项目详情"无 repo / 无 demo"的降级正确（V4）
- [ ] 移动端无横向滚动（V6）
- [ ] 推送后 5 分钟内自动上线，失败不切换线上版本（V8）
- [ ] 构建产物无凭证、无手机号、无简历下载（V9、V3 步骤 7–8）
- [ ] 订阅源可被阅读器正常导入（V5 步骤 1–2）

**M0 明确不含**：站内检索、图片多尺寸优化、分享卡片封面自动生成、海外线路。这些属后续阶段，不在首次上线的验收范围内。
